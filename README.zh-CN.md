# PikPak Rename Pro

> 一款功能丰富的 PikPak 批量文件管理工具，支持重命名、分类、去重、字幕匹配、剧集标准化和分享管理。

通过浏览器脚本批量管理 PikPak 文件。

------------------------------------------------------------------------

## 功能

### 重命名
- 多步管道 — 链式正则查找替换规则
- 按类型筛选 — 按扩展名、文件/文件夹、文件名包含内容过滤
- 大小写转换 — 转为全大写、全小写、首字母大写
- 自动编号 — 支持多种格式（01、001、A、a），可设置位置（名前/名后）、分隔符、起始值和步长
- 前缀 / 后缀 — 在文件名前或后添加文本
- 执行前预览 — 在生效前查看完整变更列表
- 暂停 / 取消 — 执行过程中可暂停或取消
- 重命名历史 — 查看历史操作并撤销（回滚）
- 预设管理 — 保存和加载重命名配置；导出/导入预设 JSON
- 复制日志 — 将操作日志复制到剪贴板

### 整理
- 自动分类 — 定义规则，按扩展名、文件名正则或类型将文件移入子文件夹
- 重复检测 — 查找并删除重复文件（识别 PikPak 的 `(1)` 后缀模式）
- 字幕匹配 — 自动将字幕文件匹配到视频文件（精确 + 模糊匹配，基于编辑距离）
- 剧集标准化 — 解析文件名中的剧集信息，统一为 S01E01 格式

### 任务
- 离线任务监控 — 查看离线下载任务状态（运行中 / 失败 / 完成）
- 自动刷新 — 可配置轮询间隔
- 重试失败 — 一键重试失败任务

### 分享
- 批量分享 — 一次性为多个文件生成分享链接
- 分享管理 — 查看、筛选（有效 / 已过期）和删除已有分享
- 有效期设置 — 1 / 7 / 30 天，可选提取码

### 通用
- 双语界面 — 中英文切换，保存偏好
- 自动认证 — 自动从 PikPak 网络请求中提取身份验证凭据
- 可拖拽面板 — 将浮动面板拖动到任意位置，位置自动记忆
- 可折叠分区 — 切换筛选和命名选项面板
- 凭据状态 — 实时显示认证就绪状态

------------------------------------------------------------------------

## 安装

1. 安装 Tampermonkey
2. 添加此脚本
3. 打开 https://mypikpak.com/

------------------------------------------------------------------------

## 使用方法

1. 打开目标文件夹
2. 等待凭据状态显示 **Ready**
3. 点击 **Scan** 扫描当前文件夹中的所有文件
4. 配置重命名规则、筛选条件和命名选项
5. 点击 **Preview** 预览变更
6. 点击 **Execute** 执行批量重命名

------------------------------------------------------------------------

## 示例

搜索：S01E(\d+)

替换：Episode_$1

------------------------------------------------------------------------

## 注意事项

- 使用前必须达到 **Ready** 状态
- 建议延迟：1000–2000 毫秒
- 无效的正则表达式将抛出错误
- 大批量数据按顺序执行（设计如此）

## 开发提示
