# PikPak Rename Pro

> 一款可靠的 PikPak 批量重命名工具，无需任何手动验证。

通过浏览器脚本批量重命名 PikPak 文件。

------------------------------------------------------------------------

## 功能

- 正则表达式查找替换 — 使用正则表达式搜索文件名并替换匹配内容
- 自动编号 — 在文件名后追加序号（`_01`、`_02`、…）
- 保留扩展名 — 重命名时可选保留原始文件扩展名
- 自动认证 — 自动从 PikPak 网络请求中提取身份验证凭据（无需手动输入令牌）
- 可调节延迟 — 设置重命名请求之间的基础延迟，附加随机抖动以避免速率限制
- 可拖拽面板 — 将浮动面板拖动到屏幕任意位置
- 凭据状态 — 实时显示认证就绪状态

------------------------------------------------------------------------

## 安装

1. 安装 Tampermonkey
2. 添加此脚本
3. 打开 https://mypikpak.com/

------------------------------------------------------------------------

## 使用方法

1. 打开目标文件夹
2. 等待凭据状态显示 **Ready**
3. 点击 **Scan** 扫描当前文件夹中的所有文件
4. 设置重命名规则 — 在 **Search** 中输入正则表达式，在 **Replace** 中输入替换文本
5. （可选）勾选 **Append index** 追加序号，或取消勾选 **Keep extension** 去除扩展名
6. 点击 **Rename** 执行批量重命名

### 重命名选项

| 设置 | 说明 |
|------|------|
| **Search** | 在文件名（不含扩展名）中搜索的正则表达式 |
| **Replace** | 替换匹配内容的文本（留空则删除匹配内容） |
| **Append index** | 在文件名后追加 `_01`、`_02`、… |
| **Keep extension** | 保留原始文件扩展名（默认勾选） |
| **Delay** | 重命名请求之间的基础延迟（毫秒），额外附加 0~600ms 随机抖动 |

------------------------------------------------------------------------

## 示例

搜索：S01E(\d+)

替换：Episode_$1

------------------------------------------------------------------------

## 注意事项

- 使用前必须达到 `Ready` 状态
- 建议延迟：1000–2000 毫秒
- 无效的正则表达式将抛出错误
- 大批量数据按顺序执行（设计如此）
